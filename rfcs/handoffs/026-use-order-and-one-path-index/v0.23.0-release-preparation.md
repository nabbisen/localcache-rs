2. **Version, as a separate commit `chore: prepare v0.23.0 (version, install examples, changelog)`.** `Cargo.toml` `[workspace.package].version` → `0.23.0`; `Cargo.lock` changes in the two workspace packages only (report its diff). Every install line in `README.md` and `docs/src/` → `0.23.0`

3. **A migration list at the head of the `[0.23.0]` section**, consolidating the Breaking entries in the order a user must act: (1) export first if you may need to go back; (2) the first writable open migrates, with its cost; (3) a migrated file does not shrink; (4) code that reads `last_accessed_at` or the export order; (5) `touch`/`set`/`batch_set` and the new error.

   `git grep -n -i "v0\.23\|0\.23\.0\|announced\|will be\|planned\|next release\|upcoming" -- docs/src README.md crates` and list every hit with a verdict. "Before v0.23.0 …" and "From v0.23.0 …" are true and stay. `docs/src/roadmap.md` and `ROADMAP.md` are mine.
